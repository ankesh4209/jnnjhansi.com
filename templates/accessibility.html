Accessibility Statement (सुगम्यता विवरण)

Commitment to ensuring digital accessibility for all citizens, including persons with disabilities.

Compliance with GIGW & WCAG 2.1

Jhansi Nagar Nigam website is designed to be accessible to all users, regardless of device, technology, or ability. It complies with World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 level AA standards and Guidelines for Indian Government Websites (GIGW).

Accessibility Features Available:

  • Text Size Adjustment: Citizens can enlarge or decrease font sizes using the A- / A / A+ controls located in the top utility bar.
  • Standard Color Contrast: Deep navy on white backgrounds ensures clear legibility and contrast ratios above 4.5:1.
  • Screen Reader Friendly: Semantic HTML5 markup, ARIA labels, and alternative text on images enable screen reading software.
  • Keyboard Navigation: All navigation menus, dropdowns, and forms can be accessed seamlessly using the keyboard Tab and Enter keys.
